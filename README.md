# 📋 Club Induction Registration Page

A simple and responsive **club induction registration website** built using **HTML, CSS, and JavaScript**.  
The application collects user details through a registration form and **stores the data locally in the browser** using Local Storage.

🌐 **Live Website:**  
👉 https://tarun-chowdary.github.io/Cbinduction/

---

## ✨ Features

- 📝 User-friendly induction registration form  
- 💾 Stores user data locally using **Browser Local Storage**  
- ⚡ Instant submission without page reload  
- 📱 Responsive design for desktop and mobile  
- 🚀 Hosted using **GitHub Pages**

---

## 🛠️ Tech Stack

- **HTML** – Structure  
- **CSS** – Styling & layout  
- **JavaScript** – Form handling & Local Storage  


---

## ⚙️ How It Works

1. User fills out the club induction form  
2. Form data is validated using JavaScript  
3. Submitted details are saved in **Local Storage**  
4. Data remains available until the browser storage is cleared  

---

## 🧪 Local Storage Usage

- Data is stored in the browser using `localStorage`  
- No backend or database is used  
- Data is device-specific and browser-specific  

---

## 🚀 Deployment

The project is deployed using **GitHub Pages**.

To deploy:
1. Push the project to a GitHub repository  
2. Go to **Settings → Pages**  
3. Select the `main` branch  
4. Save and access via the provided GitHub Pages link
